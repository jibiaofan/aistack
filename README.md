## Overview

AIStack is an open-source GPU cluster manager for AI model serving and GPU instance provisioning. It configures and orchestrates inference engines — vLLM, SGLang, TensorRT-LLM, or your own — and lets you launch SSH-accessible GPU instances on demand.

Based on GPUStack v2.2.2, rebranded with AIStack identity and custom theme (primary color: #513CC8).

## Key Features

- Broad Hardware Compatibility
- Heterogeneous GPU Scheduling
- Scaling & Multi-Node Deployment
- Multi-Inference Engine Support
- GPU Instance Provisioning
- Model Management & Playground
- OpenAI-Compatible API
- Multi-Tenant & Access Control

## Quick Start

```bash
pip install aistack
aistack start
```
